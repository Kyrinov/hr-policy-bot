# DND HR-Civ Multi-Agent Policy Advisory System

## Project Purpose

This is a pilot proof-of-concept multi-agent system for DND ADM(HR-Civ). It helps HR policy advisors obtain accurate, well-referenced guidance on federal HR policy questions by orchestrating specialist agents that fetch and analyze authoritative policy instruments.

## Architecture Summary

- **Orchestrator agent** (`src/agents/orchestrator.py`): Routes queries to specialists, synthesizes responses.
- **Specialist agents** (`src/agents/specialist.py`): 8 domain agents (staffing, classification, labour, learning, equity, ohs, languages, governance), each configured via the policy registry.
- **Web fetch engine** (`src/fetch/engine.py`): Async HTTP fetching with per-domain concurrency limits and SQLite caching.
- **FastAPI server** (`src/main.py`): Serves the GUI (static files) and handles REST + WebSocket traffic.
- **LLM client** (`src/llm/client.py`): Ollama wrapper supporting streaming and structured JSON output.
- **Database** (`src/data/db.py`): aiosqlite-based SQLite for query logging, feedback, and fetch cache.

## Key Files

| File | Purpose |
|------|---------|
| `src/data/policy_registry.json` | Canonical instrument list — 8 agents, deduplicated by URL |
| `config.yaml` | All runtime configuration (model, server, cache, logging) |
| `src/models/schemas.py` | Pydantic v2 models for all data structures |
| `src/agents/prompts/specialist_prompts.py` | System prompts for all 8 specialists |
| `src/agents/prompts/orchestrator_prompt.py` | Orchestrator system prompt |

## Implementation Rules

1. **Do not modify policy_registry.json** without updating both the JSON and the master plan.
2. **All LLM calls go through `src/llm/client.py`** — never call Ollama directly from agent code.
3. **All web fetching goes through `src/fetch/engine.py`** — never use httpx directly from agent code.
4. **All database operations go through `src/data/db.py`** — never open SQLite connections elsewhere.
5. **Structured JSON output**: Agent prompts require JSON responses. The LLM client attempts JSON parsing; handle raw text fallback gracefully.
6. **Epistemic humility**: Agents must not confabulate. If instruments don't cover the query, say so explicitly.
7. **Concurrency**: The fetch engine enforces domain-level rate limits (max 3 concurrent per domain, 1s minimum delay). Do not bypass these.

## Running the System

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
uvicorn src.main:app --host 0.0.0.0 --port 8000
```

Access GUI at http://localhost:8000.

## Hardware Context

- NVIDIA Jetson Orin AGX, 64GB VRAM
- Inference: Ollama (local)
